# Renewal Nature

## Idea

I wan to create a browser game. I use PixiJS as a base framework to create the game. My Idea is to create a single player version mix of factorio and escape from tarkov. The Player spawns in a dry distopian world where the goal is to build plants in an automated factory to renew the nature in the world. The player can then go on loot runs where he can gather the seeds, machines and ressouces for the plant factory in the main world. The player has an inventory, but if he dies, all the items are gone.

For the first step can you create a top down world where the player can move next to a helicopter to start a loot run where he gets teleported into. In the loot run there should be some extraction points, where the player needs to stay close for 10 seconds. Then the player is back in the main world
